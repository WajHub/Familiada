# Familiada

## Installation

1.  Install **NPM** **Node.js**

2.  In folder _app_ install modules:

    ```bash
    npm install
    ```

3.  Start Server

    ```bash
    npm start
    ```

    - Dev

      ```bash
      npm run electron
      ```

    - Prod

      ```bash
      npm run make
      ```

      Launch App in folder out.

## Technologies

- Electron
- Sequelize
- SQLite
- React
- Bootstrap
